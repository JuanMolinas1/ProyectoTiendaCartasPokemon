# OppenPokeCards

Proyecto Final de **Proyecto Informático II**

## Descripción

**OppenPokeCards** es un sitio web dedicado a la compra, venta y exploración de cartas Pokémon del **Pokémon Trading Card Game (TCG)**.

El proyecto busca ofrecer una plataforma donde los usuarios puedan consultar diferentes tipos de cartas, buscar cartas específicas, conocer cartas competitivas y de colección, consultar graduaciones **PSA**, comprar packs y gestionar elementos como una wishlist y un carrito de compras.

El sitio será desarrollado utilizando **HTML5, CSS3 y JavaScript**, sin frameworks ni librerías de terceros.

## Tecnologías utilizadas

* **HTML5** — Estructura y contenido de las páginas.
* **CSS3** — Diseño visual, estilos y adaptación responsive.
* **JavaScript** — Interactividad y funcionalidades dinámicas.
* **LocalStorage** — Almacenamiento de información en el navegador.
* **Git / GitHub** — Control de versiones y trabajo colaborativo.

## Páginas

El sitio estará compuesto por las siguientes páginas principales:

1. **Inicio**

   * Presentación de la tienda.
   * Cartas destacadas.
   * Cartas competitivas.
   * Cartas de colección.
   * Cartas más solicitadas.
   * Filtros.

2. **FAQ**

   * Preguntas frecuentes sobre el funcionamiento del sitio y la compra/venta de cartas.

3. **Búsqueda PSA**

   * Consulta de cartas según su graduación PSA.

4. **Búsqueda competitiva**

   * Exploración de cartas utilizadas en el ámbito competitivo del Pokémon TCG.

5. **Vender tu carta**

   * Sección destinada a usuarios que quieran ofrecer sus propias cartas para la venta.

6. **Wishlist**

   * Espacio para guardar cartas de interés.

7. **Carrito**

   * Visualización y gestión de los productos seleccionados para comprar.

8. **Página de carta**

   * Información detallada de una carta seleccionada.
